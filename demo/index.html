The policy stage is router/policy.py evaluating the same rules as config/policies.yaml: team regulated may only use local models (data residency) and always gets pii_redact, so on public-only it is refused with 403 and on smart-fast the public providers are removed from the route (try an Ollama outage: the request fails rather than falling back to a public API). Team contractors has an alias allow-list. max_tokens is clamped to 4096 (2048 for regulated). The optional OPA check is not part of the demo.

Detection comes from router/pii.py: emails, phone numbers, SSNs, Luhn-valid card numbers and API-key-like secrets, by pattern. It does not find names or addresses (the sample's customer name passes through), so it reduces exposure rather than guaranteeing it. Content logging is off by default; when a team opts in, what is stored is redacted with every detector. Audit entries carry counts, never the matched values.

Threshold calibration on the bundled pairs (measured in your browser)

Picks a threshold on half the pairs, then measures it on the other half.

Cached entries

Empty.

Same code as the gateway: router/semcache.py with its offline hashing embedder (word and character n-grams, no model). A hit needs similarity at or above the threshold and the same numbers and negations in both prompts; entries are partitioned by team and policy decision, so another team never sees them. The embedder measures wording overlap, not meaning: "rotate" vs. "revoke" an API key scores 0.88 and is a wrong hit the guards don't catch. That is why the gateway ships with the semantic cache off and the calibration here is reported as-is. The 160 pairs are short, fictional and hand-written; they are not a prediction for real traffic.

Policy from router/mcp_policy.py with the same config as config/mcp.example.yaml: default deny, per-team tool allow-lists (globs), per-key and per-team calls per minute, an identical-call limit that stops agent loops (five identical calls a minute here), daily count and spend caps, and PII-redacted arguments in the audit log.
